# Проверка личности гида и видеовизитка

Что сделано в Joldas и как это устроено. Пример на сайте — гид **Серик Жаксыбеков**
(`serik@demo.kz`): фото профиля, бейджи и видеовизитка на французском с субтитрами
на французском, английском и русском.

**Честно о границах MVP.** Проверку на живого человека (liveness) и сверку лица с документом (face match) сейчас
выполняет **модератор**: система выдаёт случайные задания для селфи и показывает сканы рядом.
Автоматическая биометрия — у сертифицированного провайдера, см. «Дальше».
Видео система проверяет **сама**: длину, громкость, долю речи и язык, и делает субтитры.

## 1. Архитектура данных

### Изменения в `guides`

| Поле | Тип | Смысл |
|---|---|---|
| `id_verified_at` | timestamptz | Когда подтверждена личность. `NULL` — не подтверждена, откликаться на заявки нельзя |
| `photo` | text | Одобренное фото профиля: имя файла в `/data/media/photos` |

### `guide_kyc` — заявка на проверку личности

| Поле | Тип | Смысл |
|---|---|---|
| `status` | `pending` / `approved` / `rejected` | Состояние заявки |
| `doc_type` | `id_card` / `passport` | Удостоверение РК или паспорт |
| `doc_file` | text, NULL после удаления | Скан документа, **зашифрован** (Fernet, ключ `KYC_KEY`) |
| `selfie_files` | text[], NULL после удаления | Кадры живого селфи, зашифрованы |
| `challenges` | text[] | Задания, выпавшие на эту попытку: `palm`, `two_fingers`, `thumb_up`, `turn_left`, `turn_right`, `touch_ear` |
| `photo_file` | text | Кандидат в фото профиля |
| `consent_at` | timestamptz | Когда дано согласие на обработку ПДн и биометрии |
| `checks` | text[] | Что подтвердил модератор: `doc_valid`, `name_match`, `liveness`, `face_match`, `photo_match` |
| `reject_reason` | text | `doc_unreadable`, `doc_invalid`, `face_mismatch`, `liveness_failed`, `photo_bad`, `name_mismatch`, `expired` |
| `reviewer_id`, `reviewed_at` | | Кто и когда решил |
| `purged_at` | timestamptz | Когда удалены сканы |

Переходы статусов:
- `pending` → `approved`: сканы удаляются, фото уходит в профиль, ставится `guides.id_verified_at`.
- `pending` → `rejected`: удаляются все файлы, гид может отправить заново — с новыми заданиями.
- `pending` дольше 30 дней → `rejected` с причиной `expired`, файлы удаляются.

### `guide_videos` — видеовизитка

| Поле | Тип | Смысл |
|---|---|---|
| `token` | text, уникальный | Папка `/data/media/videos/<token>/`: `video.mp4`, `poster.jpg`, `preview.mp4` |
| `lang` | text | Заявленный язык видео — один из языков профиля гида |
| `status` | `processing` → `review` → `approved` / `rejected`; `failed`; `replaced` | |
| `duration`, `size_bytes` | | Метаданные после перекодирования |
| `mean_volume` | real, дБ | Громкость для автопроверки звука |
| `speech_ratio` | real, 0–1 | Доля времени, где есть речь |
| `detected_lang`, `detected_prob` | | Язык, который распознал Whisper, и уверенность |
| `subtitles` | jsonb | `{"fr": "WEBVTT…", "en": "WEBVTT…", "ru": "…"}` |
| `level` | `fluent` / `conversational` / `basic` | Уровень языка по решению модератора |
| `error`, `reject_reason` | | Автоотказ (например, `duration:10`) или причина модератора |

### `guide_lang_levels` — подтверждённый уровень языка

`(guide_id, lang)` → `level`, `video_id`, `verified_at`. По этой таблице показывается бейдж
«🎥 English · Fluent». Если удалить видео, строка удаляется и бейдж пропадает.

### Файлы

- `/data/media/kyc/*.bin` — только зашифрованные сканы. Наружу отдаются через
  `/dashboard/kyc/{id}/file/…`, только админу и только пока заявка не решена, с заголовком `no-store`.
- `/data/media/photos/*.jpg` — фото 600×600. При загрузке EXIF удаляется: в нём бывает GPS.
  Публично отдаётся только одобренное фото.
- `/data/media/videos/<token>/` — видео H.264 + AAC до 720×1280 с faststart, постер и превью на 4 секунды без звука.
  До одобрения видео видят только владелец и модератор. Перемотка работает (HTTP Range).

### Обработка видео

Отдельный контейнер `worker` (`Dockerfile.worker`), лимит — 3 CPU и 3 ГБ, чтобы не тормозить сайт:
1. ffprobe проверяет длину: 30–60 с, иначе статус `failed` и уведомление гиду.
2. ffmpeg перекодирует видео и делает постер и превью.
3. volumedetect меряет громкость.
4. faster-whisper (модель `small`, CPU, int8):
   - определяет язык и считает долю речи;
   - делает субтитры на языке оригинала;
   - если язык не английский — делает английские через перевод Whisper.
5. Исходник удаляется, статус → `review`, админ получает уведомление.

Минутное видео обрабатывается примерно за 20–40 секунд.

## 2. Онбординг гида: от регистрации до допуска к заказам

1. **Регистрация** с ролью «Гид» → переход в «Профиль». Сверху карточка «Допуск к заказам»
   из трёх шагов: профиль, проверка личности (обязательно), видеовизитка (рекомендуется).
2. **Профиль:** языки, ставка за день, объекты, специализации.
3. **Проверка личности** (`/verify`):
   1. Согласие на обработку ПДн и биометрии: что собираем, кто видит, сколько храним, ссылка на закон.
      Без галочки форма не отправляется.
   2. Документ: удостоверение РК или паспорт. Фото с камеры телефона или из галереи, до 10 МБ.
   3. Живое селфи: камера включается в браузере, сервер выдаёт **два случайных задания**
      (например, «покажите два пальца», «поверните голову влево»). На каждое — кадр с камеры.
      Загрузить файл нельзя. Задания хранятся в сессии, подменить их из браузера нельзя.
   4. Фото профиля — его увидят в каталоге.
   5. «Отправить на проверку» → статус «На проверке», админам приходит уведомление.
4. **Модерация** (`/dashboard/verify` → заявка): документ, два селфи с подписями заданий и фото профиля рядом.
   - Одобрить можно, только отметив все пять пунктов: документ действителен, имя совпадает,
     задания выполнены, лицо совпадает, на фото тот же человек.
   - Отклонить — с причиной из списка. Гиду уходит уведомление.
   - При любом решении сканы удаляются с диска сразу.
5. **Допуск:** после одобрения гид может откликаться на заявки. До этого вместо отклика —
   переход на `/verify`, а в ленте висит плашка «Подтвердите личность».
6. **Видеовизитка** (`/profile/video`, можно в любой момент):
   1. Выбрать язык видео.
   2. Записать прямо в браузере (таймер, автостоп на 60 с) или загрузить MP4, WebM или MOV до 50 МБ.
   3. Воркер обрабатывает видео и отправляет модератору.
   4. Модератор смотрит видео и автопроверки, правит субтитры, при желании добавляет перевод
      на языки интерфейса и ставит уровень.
   5. Видео появляется в профиле и каталоге, у гида бейдж уровня языка.
   6. Новая загрузка заменяет прежнюю. Удалить видео — значит снять и бейдж.

## 3. Требования к интерфейсу

### Карточка гида в каталоге (`/guides`)
- Вместо буквы — одобренное фото, круг 52 px.
- Есть видео — на аватаре кнопка ▶. При наведении мыши на карточку в круге играет превью без звука.
  На телефоне и при «уменьшить движение» превью не запускается.
- Бейджи: «✓ Личность подтверждена» (зелёный), «🎥 Французский · Свободно» (синий).
- Карточка целиком ведёт в профиль. Кнопка видео открывает окно и в профиль не уводит.

### Окно просмотра видео
- Нативный `<video>` 9:16 с `playsinline`, постером и дорожками `<track kind="subtitles">`.
  Отдельной библиотеки нет.
- Субтитры по умолчанию:
  - на языке интерфейса, если такая дорожка есть;
  - иначе английские, если гид говорит не по-английски.
  - Переключение — кнопкой CC.
- Сбоку (на телефоне — снизу): имя, бейджи, уровень гида, ставка и три действия —
  «Оставить заявку», «Задать вопрос гиду» (каналы связи из модуля 9), «Открыть профиль».
- Закрывается крестиком, по Esc и кликом по фону. При закрытии видео останавливается.

### Профиль гида
- Большое фото с кнопкой ▶, бейджи под рейтингом, плашка «Видеовизитка · Французский»
  с постером 9:16. То же окно просмотра.

### Загрузка документов и селфи (`/verify`)
- Четыре нумерованных шага в одной форме.
- Для документа поле файла открывает основную камеру телефона (`capture="environment"`).
- Селфи — только с фронтальной камеры: текущее задание подписано поверх видео,
  снятые кадры видны миниатюрами, последний можно переснять.
- Нет камеры — понятное сообщение: открыть с телефона и разрешить доступ.

### Запись видео (`/profile/video`)
- Два пути: записать (камера + микрофон, таймер «0:12 / 60s», мигающая точка записи)
  или загрузить файл.
- Проверки в браузере: минимум 30 с, до 50 МБ. Полоса прогресса при загрузке.
- Подсказки: о чём рассказать (Бозжыра, Кызылкуп, Тузбаир), тихое место, лицо в кадре.

### Экраны модератора
- Очередь: проверки личности, видео на проверке, последние решения.
- Видео:
  - плеер с субтитрами;
  - таблица автопроверок с ✅/⚠️: длина, громкость (−35…−8 дБ), речь ≥ 50%,
    язык совпадает с заявленным при уверенности ≥ 70%;
  - уровни с описаниями (≈ C1+, B1–B2, A2);
  - редактор WebVTT по каждому языку, пустые поля для добавления перевода.

Всё на трёх языках интерфейса и без горизонтальной прокрутки на 375 px.

## 4. Критерии приёмки, безопасность и модерация

### Критерии приёмки (проверяются `tests/flow.sh`)

| # | Критерий | Статус |
|---|---|---|
| 1 | Непроверенный гид не может откликнуться на заявку: переход на `/verify` | ✅ |
| 2 | Без согласия заявка на проверку не сохраняется | ✅ |
| 3 | Заявка содержит документ, 2 селфи и 2 задания от сервера | ✅ |
| 4 | Скан на диске зашифрован (Fernet) | ✅ |
| 5 | Скан открывает только админ, гид получает 403 | ✅ |
| 6 | Фото до одобрения публично недоступно (404) | ✅ |
| 7 | Одобрение без всех пяти отметок не проходит | ✅ |
| 8 | После одобрения сканы удалены с диска и из БД, фото стало публичным, в профиле бейдж | ✅ |
| 9 | После одобрения отклик проходит | ✅ |
| 10 | Видео короче 30 с автоматически получает `failed` | ✅ |
| 11 | Видео 30–60 с обработано воркером и ждёт модератора | ✅ |
| 12 | До одобрения видео видят только владелец и модератор | ✅ |
| 13 | После одобрения уровень языка записан, в каталоге есть кнопка видео, превью доступно | ✅ |
| 14 | Удаление видео снимает бейдж уровня языка | ✅ |

Плюс `tests/smoke.sh`: все новые страницы × роли × 3 языка, чужая роль получает 403.

### Персональные данные (Закон РК «О персональных данных и их защите» № 94-V)
- **Согласие** — отдельное, явное, на ПДн и биометрию. Хранится дата согласия.
- **Минимизация:** после решения остаются только статус, тип документа, дата и кто решил.
  Сканов и селфи нет. Номер документа не сохраняется.
- **Срок:** сканы удаляются при решении, заявки без решения — через 30 дней (фоновая задача каждые 6 часов).
- **Защита:** сканы зашифрованы, ключ — в `.env`, в репозиторий не попадает. Доступ — только у роли admin.
  Отдаются без кэша, в URL нет прямых путей к файлам.
- **EXIF** с фото удаляется, в том числе геолокация.
- **⚠️ Локализация.** По закону ПДн граждан РК должны храниться в базе на территории Казахстана.
  Демо-сервер сейчас во Франции.
  - До запуска с реальными гидами: перенести базу и хранилище в дата-центр в РК
    или передать проверку провайдеру с хранением в РК.
  - **До этого настоящие документы не загружать.**

### Модерация контента
- **Видео отклоняется,** если: плохой звук, не тот язык, почти нет рассказа о себе,
  неуместное содержание, в кадре не сам гид. Гиду приходит уведомление с причиной.
- **Автопроверки** — подсказка, а не вердикт: решение всегда за человеком.
- **Субтитры** создаются автоматически и **обязательно вычитываются модератором**.
  Пример: в ролике Серика Whisper написал имя как «Serek» и «CEREC» и сделал ошибку
  «n'oublierz» — модератор исправил.
- **Уровень языка** ставит модератор по видео. Он подтверждает речь, но не заменяет сертификат.
